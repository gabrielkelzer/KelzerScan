# 📌 Sobre o Projeto

KelzerScan V2 é uma ferramenta desenvolvida em Python para realizar verificações de portas TCP em hosts e servidores.

O software foi criado com foco em:
- estudos de redes
- testes de conectividade
- aprendizado em sockets TCP
- programação no Termux/Linux

A ferramenta verifica automaticamente diversas portas conhecidas e informa quais estão abertas no host informado.

---

# ⚙️ Funcionalidades

✅ Scanner de portas TCP  
✅ Verificação automática de múltiplas portas  
✅ Compatível com Linux e Termux  
✅ Timeout ajustável conforme sua internet  
✅ Interface personalizada no terminal  
✅ Desenvolvido totalmente em Python

# 🚀 Instalação no Termux

```bash
termux-setup-storage

apt update && apt upgrade -y

pkg install git -y

pkg install python3 -y

git clone https://github.com/gabrielkelzer/KelzerScan

cd KelzerScan

python KelzerScan.py
```
